# سامانه مدیریت پروژه و منابع سازمانی (PMR OpenProject)

سامانه جامع مدیریت پروژه، ساختار سازمانی، گروه‌های عملیاتی و کنترل دسترسی‌های سطح ریز (Fine-Grained Permissions) بر پایه فریم‌ورک لاراول.

## ویژگی‌های کلیدی

- **مدیریت چارت سازمانی**: ساختار درختی واحدهای سازمانی (معاونت، مدیریت، واحد، تیم).
- **مدیریت پروژه‌ها و زیرپروژه‌ها**: سلسله‌مراتب پروژه‌ها، گانت چارت، و تمپلیت‌های آماده.
- **کنترل دسترسی پیشرفته**: سیستم تعیین دسترسی چندسطحی (Super Admin، مدیر واحد، ناظر، عضو).
- **چرخه تاییدات و نظارت**: مراحل تایید multi-stage برای وظیفه‌ها و پروژه‌ها.

## راهنمای نصب و راه اندازی

```bash
# نصب وابستگی‌های PHP
composer install

# تنظیم فایل محیطی و کلید برنامه
copy .env.example .env
php artisan key:generate

# اجرای مایگریشن‌ها و دیتابیس اولیه
php artisan migrate --seed

# نصب وابستگی‌های JS و بیلد Assets
npm install
npm run build
```

## اجرای سرور توسعه

```bash
composer run dev
```
